# LifeLedger — App Releases

This repository only hosts **LifeLedger Android app releases** (APK files) and the update
manifest used by the app's built-in updater. The source code is private.

* Download the latest version from **[Releases](../../releases/latest)**.
* `Lifeledger_Live_arm64.apk` — smaller, for modern 64-bit phones (most phones from 2017+).
* `Lifeledger_Live.apk` — universal, works on every Android 7.0+ phone.

Verify a download: compare its SHA-256 with `version.json` (Windows: `certutil -hashfile <file> SHA256`).

LifeLedger is an offline personal finance tracker. Your data stays on your phone.
